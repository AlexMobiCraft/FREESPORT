# Состав разделов по ролям

Согласовано с Alex 08.10.2026. «Не показывать» означает, что поле отсутствует в форме и списке, а не просто доступно только для чтения.

## Менеджер

### Клиенты (только свои, без сотрудников)

| Что | Состав |
|---|---|
| Колонки | email, ФИО, компания, ИНН, код клиента, роль, статус верификации, кандидат 1С, телефон, дата регистрации, активен |
| Фильтры | роль, статус верификации, есть кандидат 1С, активен; «Не зарегистрирован на портале» скрыт по умолчанию, показывается фильтром |
| Поиск | email, ФИО, телефон, ИНН, компания, код клиента |
| Карточка — правка | контакты, B2B-данные и реквизиты компании, адреса, активен |
| Карточка — только чтение | роль (назначается на странице подтверждения B2B, у связанного с 1С — импортом), «Связан с 1С: да/нет», вид цен из соглашения, ответственный менеджер, даты регистрации и последнего входа |
| Действия | страница подтверждения B2B, верифицировать, отклонить, заблокировать, **разблокировать** (новое), сбросить пароль, привязать к контрагенту 1С |
| Не показывать | `is_staff`, `is_superuser`, `groups`, `user_permissions`, `onec_id`, `onec_guid`, `onec_price_type_id`, `onec_link_candidates` (кроме страницы подтверждения), `sync_status`, `created_in_1c`, `needs_1c_export`, `last_sync_*`, `sync_error_message` |

### Заказы (только клиентов, у которых он ответственный)

| Что | Состав |
|---|---|
| Список | только мастер-заказы: номер, клиент, статус, оплата, сумма, число позиций, дата |
| Правка | трек-номер, дата доставки, комментарий |
| Только чтение | статус (приходит только из 1С), состав, субзаказы, адрес, способ доставки, статус оплаты, «Передан в 1С: да/нет» |
| Действия | экспорт CSV |
| Не показывать | `payment_id`, `parent_order`, `vat_group`, `status_1c`, `sent_to_1c_at` |

### Главная раздела

Счётчики со ссылкой на отфильтрованный список: «Заявки на верификацию: N, старейшая — X дней», «Новые заказы: N».

## Маркетинг

| Раздел | Доступ |
|---|---|
| Баннеры | полный: контент, таргетинг, сроки, приоритет, маркировка рекламы |
| Новости | полный |
| Блог | полный |
| Рубрики новостей и блога (`common.Category`) | полный; сейчас модель в админке не зарегистрирована |
| Товары | см. ниже |
| Бренды | «Показывать на главной», логотип, описание; без привязок к 1С и без объединения брендов |
| Категории на главной (`HomepageCategory`) | картинка, порядок, активность |
| Подписчики | только плашка на главной: «Подписчиков: N (+M за 30 дней)» |

### Товары (маркетинговый вид)

| Что | Состав |
|---|---|
| Колонки | фото, название, бренд, категория, активен, Хит, Новинка, Распродажа, Акция, Премиум, скидка %; метки правятся прямо в списке, скидка только видна |
| Фильтры | каждая метка, бренд, категория |
| Карточка | название, бренд, категория, `discount_percent` — только чтение; правка — метки |
| Массовые действия | поставить или снять каждую метку (уже есть); действий со скидкой нет |
| Не показывать | блок 1С, НДС, `slug`, `specifications`, `description`, `short_description`, варианты, цены, остатки, изображения на правку |

## Руководитель

Разделы менеджера и маркетинга целиком, без фильтра по региону, а также:

| Раздел | Состав |
|---|---|
| Сотрудники | создать, заблокировать, разблокировать, сбросить пароль, назначить одну из трёх групп. Суперпользователя и права вне трёх групп назначить нельзя, других руководителей редактировать нельзя |
| Регионы | таблица «код региона или страна → один менеджер» с названиями субъектов; блок «Не распределены: …»; резервное правило указывает на руководителя |
| Переназначение | назначить менеджера одному клиенту (ручное назначение защищено от пересчёта); массово передать всех клиентов менеджера A менеджеру B |
| Сводка | заявки на верификацию в ожидании по менеджерам со сроком; заказы и выручка за период по менеджерам и регионам; новые регистрации; верифицированные клиенты без заказов |
| Журнал действий | лента по перечню ниже, фильтр по сотруднику и периоду |
| Получатели уведомлений | `NotificationRecipient` |
| Бонусная программа | `BonusProgramSettings`; операции бонусов — только просмотр |

## Перечень действий для журнала (CAP-6)

Верификация, отказ, блокировка, разблокировка, сброс пароля, смена роли, привязка к 1С, смена трек-номера, даты доставки или комментария заказа, назначение и переназначение ответственного менеджера, изменение правила региона, создание, блокировка и смена группы сотрудника.

## Ни одной из ролей

Журналы аудита (в сыром виде) и синхронизации, `SyncConflict`, сессии импорта и их запуск, мониторинг, все привязки к 1С (`Brand1CMapping`, `Attribute1CMapping`, `AttributeValue1CMapping`), `OnecExcludedItem`, `PriceType`, `ColorMapping`, `Attribute`, `AttributeValue`, `ProductVariant`, дерево категорий каталога, `DeliveryMethod`, `Page`, `UserConsent`, `Cart`, `Favorite`, группы и права Django.
