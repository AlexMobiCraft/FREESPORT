## Intent

**Problem:** Заказ клиента, загруженный БУС с сайта, получает Менеджера и Автора = пользователь сеанса обмена (`<Не указан>` у фонового задания), Подразделение пустое (63 из 64 заказов в test_base). Без этих полей менеджеры не могут работать с заказом.

**Approach:** Только настройкой соответствий реквизитов БУС, без правок кода сайта и расширения: Менеджер = «Основной менеджер» партнёра, Подразделение = подразделение этого менеджера, Автор = руководитель «Чернов В (Менеджер)». Регламент для администратора 1С, проверка на test_base.

## Boundaries & Constraints

**Always:**
- Источник менеджера — `Партнер.ОсновнойМенеджер` в 1С (решение владельца 09.11.2026).
- Запасной менеджер и Автор всех заказов с сайта — «Чернов В (Менеджер)» (решение владельца). Запасное подразделение — «Отдел продаж».
- Менеджер недействителен (`Недействителен = Истина`) → запасной менеджер.
- Повторная загрузка существующего заказа не меняет Менеджер, Подразделение и Автора — ручную переназначку в 1С обмен не затирает.
- Настройка применяется к каждой настройке обмена, которая загружает заказы.
- Уже загруженные заказы не дозаполняются — менеджеры правят их вручную (решение владельца 09.11.2026).

**Never:**
- Не править код сайта, XML заказа и модули расширения БУС.
- Не искать пользователей по наименованию в тексте алгоритма — ссылки выбираются в форме настройки.
- Не записывать настройки обмена через COM на проде; на test_base — только с резервной копией.

## Design Notes

Строка «Автор» стоит после «Партнер», поэтому алгоритм видит заполненного партнёра; строка «Менеджер» к этому моменту уже поставила запасного (Чернова):

```bsl
Если [Документ].ЭтоНовый() Тогда
	[Результат] = [Документ].Менеджер; // запасной менеджер = автор
	ОснМенеджер = [Документ].Партнер.ОсновнойМенеджер;
	Если ЗначениеЗаполнено(ОснМенеджер) И НЕ ОснМенеджер.Недействителен Тогда
		[Документ].Менеджер = ОснМенеджер;
		Если ЗначениеЗаполнено(ОснМенеджер.Подразделение) Тогда
			[Документ].Подразделение = ОснМенеджер.Подразделение;
		КонецЕсли;
	КонецЕсли;
Иначе
	[Документ].Менеджер = [Документ].Ссылка.Менеджер;
	[Документ].Подразделение = [Документ].Ссылка.Подразделение;
	[Результат] = [Документ].Ссылка.Автор;
КонецЕсли;
```

Если порядок строк окажется другим (Автор раньше Партнера), алгоритм молча оставит запасного менеджера — проверка порядка обязательна в регламенте.
