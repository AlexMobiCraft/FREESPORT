## Intent

**Problem:** Страница товара без выбранного варианта (товар без вариантов, товар с опциями до автовыбора) показывает тренеру и представителю федерации розницу, и JSON-LD называет ту же сумму. Список и деталь товара не отдают `trainer_price` и `federation_price`, поэтому `price.trainer` и `price.federation` пусты, а `getPriceForRole` откатывается на розницу. Бэкенд при этом считает этим ролям их цену (`get_price_for_user`).

**Approach:** `getProductDisplayPrice` берёт `current_price` из ответа API для любой роли, кроме гостя, если он больше нуля, — это та сумма, что платит клиент в корзине и заказе. Поля `trainer_price` и `federation_price` в сериализатор не добавляются: список каталога открыт анонимам, и новые поля показали бы им цены тренеров и федераций.

</frozen-after-approval>

## Implementation Notes

- Решение владельца 01.11.2026: «Тренер и представитель федерации должны сразу видеть свою цену». Из двух вариантов отложенного пункта выбран второй (`current_price`): он не открывает новых данных публично и не меняет API, OpenAPI и типы.
- `frontend/src/utils/pricing.ts` — `getProductDisplayPrice`: перед ветками VIP/акции для `userRole !== 'guest'` берётся `current_price > 0`. Гость идёт прежним путём (розница или акция): страница строится на сервере по сессии, но правило то же, что у плитки.
- Побочное следствие: неверифицированный B2B-клиент, которого бэкенд понижает до розницы, теперь видит розницу, а не цену роли, которой не платит.
- Тесты: `pricing.test.ts` (тренер, федерация, откат без `current_price`, оптовик, которого backend понизил до розницы, гость), `ProductInfo.test.tsx` (экран по форме реального ответа), `ProductPageClient.jsonld.test.tsx` (SSR и после монтирования для тренера и федерации). Без правки падают 8 новых тестов.
- Потребители `getProductDisplayPrice` (GitNexus `impact`, риск LOW): только `ProductInfo` и `ProductPageClient`.
- Проверено: `npm run format:check`, `npm run lint`, `npx tsc --noEmit` чисты; `detect-changes` — затронут один символ; циклы импорта — только базовая линия.
- Закрытый пункт «Отложено из ревью spec-d14-2-jsonld-wholesale-price.md» перенесён из `deferred-work.md` в архив.
