**Реестр должен содержать для каждого пункта:** исходное слово, URL/контекст отчёта, решение, основание, владелец изменения, статус, способ проверки. Начальные группы:

- адрес/технические идентификаторы: `semerukdv`, `email`;
- интерфейс и редактура: `privacy`, `блог`, `менеджер`, `персонал`, `фитнес`, `хит`, `brand`;
- смешение алфавитов: `CRM-системе` — закрыто доказательством production API.
- доступное имя навигации: `Breadcrumb` — по материалам проверки уже заменено в трёх компонентах; включить доказательство в реестр без повторной реализации. Итого начальный перечень содержит все 19 элементов.
