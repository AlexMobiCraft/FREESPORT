## Intent

**Problem:** У заказа клиента, который БУС загрузил с сайта, Автор = `<Не указан>`. Типовая подписка УТ `УстановитьАвтораОбъекта` (BeforeWrite, источник `ДокументОбъект.ЗаказКлиента`) записывает каждому новому документу `Автор = Пользователи.АвторизованныйПользователь()`, затирая значение строки соответствия «Автор». Регламентное задание БУС создаётся без пользователя ИБ, поэтому авторизованный пользователь — `<Не указан>`.

**Approach:** Регламентное задание БУС, которое загружает заказы, выполняется от имени служебного пользователя ИБ «Выгрузка на сайт». Тогда Автор новых заказов — «Выгрузка на сайт». Изменение только в настройке 1С и в регламенте: без кода, без правки расширения БУС и типовой конфигурации.

## Boundaries & Constraints

**Always:**
- Автор заказов с сайта — служебный пользователь «Выгрузка на сайт» (решение владельца 16.11.2026, заменяет «Чернов» от 09.11.2026).
- Пользователь указывается у задания каждой настройки БУС с «Загружать заказы = Да».
- До указания проверить, что у «Выгрузка на сайт» есть пользователь ИБ и группа доступа «Администраторы», как на test_base. Если прав меньше, не применять: загрузка с ограниченными правами не проверена и может встать целиком.
- Менеджер и Подразделение заполняются по-прежнему, по регламенту `order-manager-author-department-setup.md`.
- Повторная загрузка существующего заказа Автора не меняет: подписка срабатывает только для новых документов.
- Сначала test_base, на проде — только по регламенту, выполняет администратор 1С.

**Never:**
- Не править код сайта, XML заказа, модули расширения БУС и типовую конфигурацию УТ.
- Не дозаполнять Автора у уже загруженных заказов.

## Implementation Notes

**Проверка причины на test_base 16.11.2026.** В конец алгоритма строки «Автор» настройки «Загрузка заказов локально» временно добавлена строка, которая пишет в Комментарий `[Документ].ЭтоНовый()`, пользователя сеанса и `[Результат]`. Затем настройка восстановлена из побайтовой копии (совпадение подтверждено).
- Заказ сайта 90001260121 → новый СМУТ-025852: `новый=Да`, сеанс без пользователя, **`результат=Чернов В (Менеджер)`**, Менеджер Исакова, Подразделение «Отдел продаж». Итоговый Автор — **`<Не указан>`**. Алгоритм отдал Чернова, а значение затёрто при записи.
- Ловушка локального стенда: сайт шлёт `Ид = order-{pk}`. После пересоздания локальной БД pk повторяются, и БУС по `БУС_ИдентификаторыОбъектов` обновляет апрельский документ, а не создаёт новый (ветка `Иначе`, Автор/Менеджер берутся из старого документа). Так прошли заказы 90001260101/111 (→ СМУТ-025850/51, v1 от 22.04.2026, `tempadmin`) и заказы B/C от 14.11 (→ 025847/49). Для проверки последовательность `orders_id_seq` локальной БД сдвинута на 200: в регистре заняты `order-4…92`.

**Решение на test_base 16.11.2026.** Пользователь ИБ «Выгрузка на сайт» (профиль «Администратор») указан у задания «(БУС) Обмен с БУС: Загрузка заказов локально» (было пусто). Заказ сайта 90001260131 → новый СМУТ-025853: Автор «Выгрузка на сайт», Менеджер Исакова, Подразделение «Отдел продаж», проведён. Настройка задания на test_base оставлена.
