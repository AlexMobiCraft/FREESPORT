## Intent

**Problem:** `/requisites` показывает устаревшие реквизиты ООО «ФРИСПОРТ» (ИНН 7810755524, СПб, Терещенко Р.Г.). Актуальные данные — два ИП — лежат в `tmp/rekvizty.html` и не опубликованы.

**Approach:** Переписать статический контент страницы двумя блоками — «Владелец сайта» (ИП Терещенко Л.В.) и «Пользователь сайта» (ИП Семерюк Д.В.), сохранив вёрстку, компоненты и типографику. Только контент и метаданные, без новых компонентов и без API.

## Boundaries & Constraints

**Always:**
- Значения переносятся из `tmp/rekvizty.html` **посимвольно** (наименование, адреса, ИНН, ОГРНИП, р/с, к/с, БИК, банк, директор, почта, GLN). Цифры не переформатировать.
- Порядок строк внутри блока — как в источнике.
- Сохранить токены страницы: `bg-canvas`, `bg-panel`, `text-headline-l`/`text-display-m`, `text-title-l`, `text-body-s`/`text-body-m`, `text-text-primary`/`text-text-muted`, `divide-neutral-300`, `py-8 sm:py-12`, `p-6 sm:p-8`.
- Server Component (без `'use client'`), маршрут и хлебные крошки не менять. Комментарии — на русском.

**Ask First (решено человеком 2026-08-22):**
- Строка «Директор» **удалена** у обеих организаций: у ИП нет директора, значение дублировало наименование.
- Телефон и почта **оформлены ссылками** `tel:`/`mailto:`.
- Расчётные счета **остаются** на странице; расхождение контактов с подвалом сайта **оставлено осознанно**.
- Любое дальнейшее отклонение состава реквизитов от источника — снова через вопрос человеку.

**Never:**
- Не сохранять данные ООО «ФРИСПОРТ», включая телефоны `+7 (8652) 22-50-78`, `+7 (8652) 90-97-71`, `+7 (968) 273-21-68` и `info@optisport.ru`.
